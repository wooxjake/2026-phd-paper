# 3-4. 복부 EMG 채널 포함 여부 — 등만 측정해도 되는가

`method/3-1`(전극 위치)과 `method/3-3`(피로 지표 산출) 작성 시 「필수: 요추기립근, 권고: 다열근, 선택: IO/TrA」로 미결 처리해 두었던 사항을 원문 대조로 확정한다. 작성일 2026-08-19.

**결론부터: 등에만 붙이면 안 된다.** 아래 3가지 질문에 대한 답을 순서대로 정리한다.

---

## 1. 복부 EMG 변인이 유의한 변화를 보인 선행연구가 있는가 — 있다

수집 문헌 중 지속 좌식(2시간 이내) 프로토콜에서 복부 근육 EMG를 측정한 5편을 전수 대조하였다.

| 문헌                            | 좌식 시간·조건                                        | 측정한 복부 근육                              | 결과                                                                                                            |
| ------------------------------- | ----------------------------------------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Jia & Nussbaum (2018)**       | **40분**, 등받이 없는 스툴, 무지지 좌식(의자 좌식)    | 양측 **외복사근(EO)·내복사근(IO)·복직근(RA)** | **4/6 채널 유의**(LEO p=0.03, LIO p=0.02, RIO p=0.02, RRA p=0.03) / **2/6 채널 비유의**(LRA p=0.12, REO p=0.86) |
| **Waongenngarm et al. (2015b)** | **60분**, 직립/구부정/전방굴곡 3자세, 스툴(의자 좌식) | 양측 **IO/TrA**, **복직근(RA)**               | **IO/TrA만 구부정 자세에서 유의**(우 p=0.002, 좌 p=0.006) / **RA는 전 자세에서 비유의**(F=0.301-2.193, p>0.05)  |
| **Jung et al. (2021)**          | **30분**, 등받이·책상 없는 의자(의자 좌식)            | 양측 **내복사근/복횡근(IO/TrA)**              | **비유의**(RT IO p 포함 전체 p=0.927-0.898)                                                                     |
| **Baker et al. (2018)**         | **120분**, 사무용 컴퓨터 작업(의자 좌식)              | 우측 **외복사근(EO)** 1채널                   | **비유의**(진폭·중앙주파수 모두 변화 없음)                                                                      |

**핵심 발견 — Jia & Nussbaum (2018)은 본 연구와 조건이 가장 가까운데, 복부 근육의 다수 채널에서 유의한 저하를 보였다.**

40분 무지지 의자 좌식(스툴, 등받이 없음)에서 12개 체간근 전부를 측정한 결과:

| -------- | ----------------- | --------------- |
| **복부** | LEO(좌외복사)     | **유의** p=0.03 |
|          | LIO(좌내복사)     | **유의** p=0.02 |
|          | LRA(좌복직근)     | 비유의 p=0.12   |
|          | REO(우외복사)     | 비유의 p=0.86   |
|          | RIO(우내복사)     | **유의** p=0.02 |
|          | RRA(우복직근)     | **유의** p=0.03 |
| **배부** | LMF(좌다열근)     | 비유의 p=0.15   |
|          | LEL(좌요추기립근) | **유의** p<0.01 |
|          | LET(좌흉추기립근) | **유의** p=0.02 |
|          | RMF(우다열근)     | **유의** p<0.01 |
|          | REL(우요추기립근) | **유의** p=0.02 |

**복부(4/6) 대 배부(5/6) — 유의 비율이 거의 같다.** 40분 좌식에서 복부 근육이 등 근육보다 덜 민감하다는 근거는 없다. 오히려 좌측 다열근(등)은 비유의였는데 좌측 내·외복사근(배)은 유의했다.

> **이전 기록 정정.** `method/3-3` 작성 시 "IO/TrA만 검출되었다"는 서술은 Waongenngarm(2015b) 한 편만 근거로 삼은 것이었다. Jia & Nussbaum(2018)까지 포함하면 **복부 근육이 등 근육보다 결코 덜 반응적이지 않다.**

## 2. 앉은 자세에서 복부의 피로도·근활성을 봐야 할 필요가 있는가 — 있다

세 가지 근거가 있다.

### (1) 기전상 복부 심부근이 요추 정렬을 직접 통제한다

Areeudomwong et al. (2012)이 인용한 Harrison et al. (1999)·Kavcic et al. (2004)의 논리는 다음과 같다.

> 다열근(MF)과 내복사근/복횡근(IO/TrA)은 상부 요추 분절의 압박력을 상쇄하고 요추 안정성을 높이는 국소 시스템을 구성한다. 좌식 중 이 근육들의 지속 수축이 근피로의 원인이 되고, 장기적으로 요통 발생과 연결될 수 있다.

즉 IO/TrA는 배 근육이라서 부수적으로 보는 것이 아니라, **다열근과 짝을 이루어 요추를 안정화하는 심부 코어 시스템의 절반**이다. 요추기립근만 보면 이 시스템의 절반을 놓친다.

### (2) 자세에 따라 복부 근육의 활성 패턴이 달라진다

Waongenngarm et al. (2015a, 진폭 비교)에서 **직립 좌식이 구부정 좌식보다 IO/TrA 활성을 유의하게 더 크게 유도**했다(p 수준 명시, 직립 > 구부정). 즉 IO/TrA 활성도는 자세 변화를 반영하는 지표다. 본 연구가 자발적 자세 변화(바른 자세 → 구부정 방향 이동)를 관찰하는 설계이므로, IO/TrA 활성 저하가 **자세 붕괴의 근전도 상관물**로 기능할 가능성이 있다.

### (3) 좌식 자세가 복부 활성을 억제한다는 독립적 근거

Waongenngarm et al. (2015b)에서 구부정 좌식은 다른 두 자세보다 IO/TrA MDF 저하가 뚜렷했다. 본 연구가 다루는 바른 자세에서 구부정 자세로의 자발적 이동 과정과 정확히 대응하는 현상이다.

## 3. 등에만 EMG를 붙여도 괜찮은가 — 안 된다, 최소 IO/TrA는 포함해야 한다

### 3.1 등만 측정하면 놓치는 것

| 놓치는 정보                                                                      | 근거                                     |
| -------------------------------------------------------------------------------- | ---------------------------------------- |
| 40분 좌식에서 복부 4채널 중 4개가 유의하게 변했다는 신호(Jia)                    | 등만 보면 이 정보 자체가 존재하지 않는다 |
| 구부정 자세로의 이동을 가장 민감하게 반영하는 근육(IO/TrA, Waongenngarm 2015a·b) | 자세 변화의 근전도 상관물을 놓친다       |
| 다열근-IO/TrA 심부 코어 시스템의 절반                                            | 기전 해석이 불완전해진다                 |

### 3.2 등만 측정해도 되는 근거는 있는가 — 제한적으로만 있다

Baker(120분)와 일부 Waongenngarm 결과(RA 비유의)는 복부가 등보다 둔감할 수 있다는 근거이지만, 두 가지 한계가 있다.

- Baker는 **외복사근 1채널만** 측정했다. 내복사근·복횡근·다열근 조합이 아니므로 "복부 전체가 둔감하다"는 결론의 근거로 쓰기 약하다.
- Waongenngarm(2015b)의 비유의 채널은 **복직근(RA)**이다. RA는 굴곡근이며 자세 안정화보다 체간 굴곡에 관여하므로, 애초에 좌식 안정화 과제에서 활성이 낮을 것으로 예상되는 근육이다. IO/TrA와 같은 범주로 묶어 "복부는 둔감하다"고 일반화하면 안 된다.

### 3.3 권고 — 최소 구성

| 우선순위                 | 근육                        | 채널 | 근거                                                                                                                                                                  |
| ------------------------ | --------------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **필수**                 | 요추기립근                  | 양측 | `method/3-1` 기존 결정                                                                                                                                                |
| **필수로 격상**          | **내복사근/복횡근(IO/TrA)** | 양측 | Jia(40분, 4/6 복부 채널 유의), Waongenngarm(60분, 유일하게 유의한 근육), Areeudomwong(30분, 바닥 좌식에서 유의) — **세 편 모두에서 반응성이 확인된 유일한 복부 근육** |
| 권고 유지                | 다열근                      | 양측 | `method/3-1` 기존 결정과 동일                                                                                                                                         |
| **하향 — 선택 사항으로** | 복직근(RA)                  | —    | Jia에서 2/2 비유의, Waongenngarm에서 비유의. 굴곡근이라 좌식 안정화 과제 특성과 맞지 않음. 채널 여유가 있을 때만 추가                                                 |
| 하향 — 근거 약함         | 외복사근(EO)                | —    | Baker 단독 비유의, Jia에서 2/2 중 1개만 유의(REO 비유의, LEO 유의로 편측 불일치). 판단 보류                                                                           |

**즉 `method/3-1`에서 "선택"으로 두었던 IO/TrA를 필수로 올리고, 대신 복직근·외복사근을 선택 항목으로 내린다.**

### 3.4 전극 위치 (기존 대조 재확인)

| 근육                  | 위치                                 | 출처                                                        |
| --------------------- | ------------------------------------ | ----------------------------------------------------------- |
| **IO/TrA**            | 전상장골극에서 정중면 쪽 **1cm**     | Areeudomwong (2012), Waongenngarm (2015b), Jung (2021) 공통 |
| 복직근(RA, 선택 시)   | 배꼽 외측 2-3cm                      | Jia & Nussbaum (2018)                                       |
| 외복사근(EO, 선택 시) | 늑골연 최하점-반대측 치골결절 연결선 | Baker (2018)                                                |

`method/3-1` 1.3절에 이미 기재된 위치와 동일하다. 변경할 것은 우선순위뿐이다.

**촉진·검증 절차와 양측 부착 근거**는 IO/TrA를 포함한 전 채널에 공통 적용되므로 여기서 반복하지 않는다. `method/3-1` **1.4절**(근육 위치 확인 — 촉진 및 저항수축 검증)과 **1.5절**(좌우 양측 부착 이유)을 참조한다. 특히 1.5절의 Jia & Nussbaum(2018) 좌우 비대칭 사례(외복사근 좌측만 유의, 복직근 우측만 유의)는 이 문서의 3.3절에서 EO·RA를 "선택(근거 약함)"으로 분류한 판단과 직결된다 — 편측 결과만으로 "이 근육은 비유의하다"고 단정하면 안 되는 이유이기도 하다.

## 4. 채널 수 증가에 따른 실무적 고려

| 항목                   | 영향                                                                                                                                                                                                                                                                    |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 부착·준비 시간         | 편측 2근육(요추기립근·다열근) → 편측 3근육(+IO/TrA)으로 증가 시 세션당 준비 시간 소폭 증가                                                                                                                                                                              |
| 세션 전 안정 시간 확보 | `method/2-1`의 안정화 구간(첫 1분 제외) 방침은 채널 수와 무관하게 유지                                                                                                                                                                                                  |
| 저활성 에포크 문제     | IO/TrA는 요추기립근보다도 활성이 낮을 수 있어 `method/3-3`의 저활성 구간 제외 기준이 IO/TrA에서 더 자주 발동할 가능성이 있다. 근육별로 제외 비율을 따로 보고해야 한다                                                                                                   |
| RVC 정규화             | IO/TrA를 추가하면 `method/3-2`의 RVC 과제 목록에 IO/TrA 과제가 필요하다. Baker(2018)의 외복사근 RVC 과제(앙와위, 고관절 45°·슬관절 90°, 양다리 1cm 거상)를 IO/TrA에도 준용할 수 있는지는 원문에 IO/TrA 전용 RVC가 명시되어 있지 않아 별도 확인이 필요하다 `[확인 필요]` |

## 6. 결정 사항 요약

1. **복부 채널을 포함한다.** 등만 측정하는 안은 채택하지 않는다.
2. **IO/TrA를 필수 채널로 격상한다.** `method/3-1`의 「선택」 표기를 「필수」로 수정해야 한다.
3. **복직근·외복사근은 선택 사항으로 유지한다.** 채널 여유가 있을 때만 추가한다.
4. **최종 전극 구성(안)**: 요추기립근(양측, 필수) + 다열근(양측, 권고) + **IO/TrA(양측, 필수)** = 최소 편측 3근육, 양측 6채널.
