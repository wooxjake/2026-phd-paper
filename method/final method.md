# 최종 변인 및 분석계획

작성일: 2026-09-04

## 1. 문서 용도

이 문서는 본 연구의 최종 변인 설정과 분석방법만 요약한다. 변인의 산출식, 장비 설정, 전처리, 신호품질, 제외 기준, 검정력 분석 및 예비자료로 확정할 항목은 method 폴더의 세부 문서에서 관리한다.

## 2. 분석 원칙

본 연구는 규칙적 운동 참여군과 비규칙적 운동군을 대상으로 30분간 의자에 앉은 자세를 유지하는 동안 나타나는 요추각과 체간근 반응의 시간적 차이를 비교한다.

결과변인은 중요도에 따른 위계를 두지 않고 다음 네 검정군으로 구분한다.

- 요추각 파형군
- EMG 파형군
- 요추각 단일 요약값군
- 자세조정 사건군

각 검정군의 유의수준은 `.05`로 설정한다. 검정군 사이에는 추가적인 보정을 적용하지 않는다. 본 연구는 비무작위 횡단 집단비교 연구이므로 집단 차이를 규칙적 운동 참여의 인과적 효과로 해석하지 않는다.

## 3. 최종 변인 설정

### 3.1 요추각 파형군

| 변인                             | 표기    | 분석방법          |
| -------------------------------- | ------- | ----------------- |
| 기준각 대비 시간별 요추각 변화량 | ΔLLA(t) | SPM1D 이표본 검정 |

시간별 IMU 기반 요추 절대각 `LLA_ang(t)`는 집단별 평균 파형으로 제시하되, 별도의 집단 간 추론 검정은 시행하지 않는다.

### 3.2 EMG 파형군

| 변인                   | 표기              | 분석방법                        |
| ---------------------- | ----------------- | ------------------------------- |
| 시간별 정규화 EMG 진폭 | normalized RMS(t) | 근육별·좌우별 SPM1D 이표본 검정 |
| 시간별 EMG 중앙주파수  | MDF(t)            | 근육별·좌우별 SPM1D 이표본 검정 |

### 3.3 요추각 단일 요약값군

| 변인                         | 표기                   | 분석방법    |
| ---------------------------- | ---------------------- | ----------- |
| 세션 전체 평균 요추각 변화량 | LLA_dev_avg            | Welch t검정 |
| 종료 구간 요추각 변화량      | LLA_dev_final          | Welch t검정 |
| 최대 굴곡 시 요추각 변화량   | LLA_max_flexion_change | Welch t검정 |

세션 전체 평균 요추 절대각 `LLA_avg`는 기술통계로만 제시한다.

### 3.4 자세조정 사건군

| 변인                | 표기        | 분석방법                |
| ------------------- | ----------- | ----------------------- |
| 단계적 자세 전환 수 | shift_count | 포아송 또는 음이항 회귀 |

### 3.5 기술통계 제시 변인

- 시간별 IMU 기반 요추 절대각 `LLA_ang(t)`
- 세션 전체 평균 요추 절대각 `LLA_avg`
- 전체 자세조정 사건 수
- `fidget` 수
- `shift` 진폭
- `fidget` 진폭

## 4. 검정군별 분석 방법

| 검정군               | 변인                                               | 분석방법                | 검정군 기준                            |
| -------------------- | -------------------------------------------------- | ----------------------- | -------------------------------------- |
| 요추각 파형군        | ΔLLA(t)                                            | SPM1D 이표본 검정       | 제1종 오류율 α=.05, 파형 내부 RFT 보정 |
| EMG 파형군           | 근육별·좌우별 normalized RMS(t), MDF(t)            | SPM1D 이표본 검정       | 거짓발견률 q=.05, 파형 내부 RFT 보정   |
| 요추각 단일 요약값군 | LLA_dev_avg, LLA_dev_final, LLA_max_flexion_change | Welch t검정             | 제1종 오류율 α=.05, Holm 보정          |
| 자세조정 사건군      | shift_count                                        | 포아송 또는 음이항 회귀 | 제1종 오류율 α=.05                     |

## 5. 상세 내용의 위치

- 기준각 정의, IMU 센서 부착, 각도 산출: `method/4. IMU - LLA/`
- EMG 측정, 정규화, 피로지표: `method/3. EMG - fatigue,RVC/`
- 좌식 세션 절차: `method/2. Sitting Time/`
- 연구대상과 집단 정의: `method/1. Subjects/`
- 통계 절차와 보정 원칙: `method/6. Statistic/`
- 설문 및 주관적 지표: `method/5. Survey/`

## 6. 제외한 분석

- 기준각 이탈 상태, 이탈 지속시간 및 기준각 복귀 판정
- Slump 발생 잠재시간
- 전반 15분과 후반 15분의 사건 수 비교
- 블록별 요추각 및 EMG 평균 비교
- 공변량을 포함한 공분산분석과 다중회귀
- 사건 간 평균 간격
- Shift와 fidget 합산값의 집단 간 추론 검정
- 굴곡 방향과 신전 방향으로 나눈 shift 수의 집단 간 추론 검정
- LLA_avg의 별도 집단 간 추론 검정
- 요추각 또는 자세조정 사건과 불편감의 관련성 분석
